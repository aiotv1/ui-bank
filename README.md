# UI BANK — نموذج تجريبي لتصميم واجهة تطبيق بنكي

> **هذا المشروع نموذج تجريبي (Prototype) وفكرة تصميم واجهة (UI Design Concept) فقط.**
> **ليس تطبيقاً حقيقياً، ولا يمثل أي بنك، ولا يقدّم أي خدمة مصرفية.**

## الغرض

هذا المشروع تعبير عن رأي في تجربة الاستخدام (UX) وتصميم الواجهة (UI) لتطبيق بنكي للهاتف. الهدف هو عرض أفكار تصميمية مثل ترتيب الشاشات، وسهولة الوصول إلى الخيارات، ووضوح الحالات، ودعم الوضع الداكن واللغات المتعددة، ومناقشتها.

لا يوجد في المشروع أي احتيال أو انتحال لهوية أي جهة، ولا يهدف إلى خداع أحد أو جمع أي بيانات.

## تنبيهات مهمة

- **البيانات كلها وهمية:** الأسماء والحسابات وأرقام الـ RIB والـ IBAN والعمليات والتواريخ والعناوين والهواتف والبريد الإلكتروني، كلها مختلقة.
- **لا يُحفظ شيء:** لا يوجد خادم (Backend) ولا قاعدة بيانات. أي معلومة تُدخل في الحقول تبقى في الصفحة فقط ولا تُرسل إلى أي جهة.
- **الاسم والشعار وهميان:** الاسم «UI BANK / يو آي بانك» والشعار من تصميم مستقل ولا يخصان أي مؤسسة قائمة.
- **رمز الدخول تجريبي:** أي رمز يُستخدم في الشاشات هو رمز للعرض فقط، ولا يمثل رمزاً حقيقياً.
- **لا تُدخل بياناتك الحقيقية** في هذا النموذج.

## ملاحظة عن المرجع

بدأ العمل بالنظر في واجهات تطبيق بنكي حقيقي بهدف **نقد تجربة الاستخدام** واقتراح تحسينات عليها. وبعد ذلك استُبدلت كل الأسماء والشعارات والروابط والمعلومات الحقيقية بعناصر وهمية، ولم يتبقَّ منها شيء في الملفات. لا يوجد أي ارتباط رسمي بين هذا المشروع وأي بنك.

## تشغيل المشروع

الملف الرئيسي هو [index.html](index.html)، ويمكن فتحه مباشرة في المتصفح.

أو تشغيله عبر خادم محلي:

```bash
python -m http.server 5173
```

ثم افتح الرابط:

```
http://localhost:5173/index.html
```

يُعرض التطبيق داخل إطار هاتف على الشاشات العريضة، وبملء الشاشة على الهاتف.

## ما الذي يحتويه النموذج

- شاشة الدخول وتذكّر الحساب والدخول بالبصمة (عرض فقط).
- الصفحة الرئيسية وبطاقة الحساب وعمليات الحساب.
- الإشعارات، وصفحة اكتشاف المنتجات.
- التحويلات مع المستفيدين، وإدارتهم.
- البطاقات وسقوف الاستخدام.
- الإعدادات وصفحاتها الفرعية، وسياسة الخصوصية.
- فتح حساب وتتبع الطلب، وطلب الاتصال بالمستشار.
- الوضع الداكن التلقائي، واللغات: العربية والفرنسية والإنجليزية والإسبانية.

## ترخيص الاستخدام

المشروع للعرض والنقاش والتعلم. لم يُحدَّد ترخيص مفتوح المصدر بعد، ولا يجوز استخدام الشعار أو الاسم المعروضين لأي غرض تجاري أو لتقديم خدمة مالية حقيقية.
